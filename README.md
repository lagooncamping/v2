# เว็บ The Lagoon Camping Resort (เวอร์ชัน 2 · ไทย + English)

## ดูเว็บ
ดับเบิลคลิกไฟล์ `index.html` ได้เลย (หน้าภาษาอังกฤษอยู่ในโฟลเดอร์ `en/` หรือกดปุ่ม EN ที่เมนู)

## ของใหม่เมื่อเทียบกับเวอร์ชันเดิม
- มีภาษาอังกฤษครบทุกหน้า และมีปุ่มสลับ TH / EN
- แก้ราคา เบอร์โทร หรือเวลาเช็กอิน ที่ไฟล์ `js/data.js` ที่เดียว เปลี่ยนทั้งเว็บ
- เมนูกับท้ายเว็บอยู่ใน `js/layout.js` ที่เดียว (ไม่ต้องแก้ทีละหน้า)
- หน้า "ที่พัก & ราคา" รวมราคาและการ์ดบ้านแต่ละแบบ มีปุ่ม "จองหลังนี้"
- คำถามที่พบบ่อย (FAQ) ในหน้าข้อมูลเข้าพัก
- ปุ่มโทร / LINE ลอยมุมจอบนมือถือ
- แผนที่ Google Maps ในหน้าติดต่อ
- ลิงก์ไปอ่านรีวิวจริงบน Facebook
- ไฟล์สำหรับ Google: ข้อมูลธุรกิจ (schema), `sitemap.xml`
